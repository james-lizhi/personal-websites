# 李智个人作品集 · 副本

完整的静态网页与资源位于 `docs/`，主页为 `docs/index.html`。

## GitHub Pages

使用 `main` 分支的 `/docs` 作为发布源。项目站点地址为 [李智个人作品集 · 副本](https://james-lizhi.github.io/personal-websites/)。

页面使用相对资源路径，适用于 GitHub Pages 的项目子路径。`docs/.nojekyll` 让 GitHub Pages 直接发布静态文件。

## 本地预览

安装 Node.js 后，在此目录运行 `node serve.mjs`，打开 http://localhost:4173 。无需安装依赖或构建。`docs/` 可以直接部署到静态服务器。

`docs/projects.js` 是作品目录，记录封面、标题、分类、完整跨页顺序与原 PDF 页码。当前详情使用 `docs/assets/projects/` 下的 17 张 `spread-*.webp` 图片，每张均从原始 PDF 直接渲染为完整的 3508 × 1240 像素跨页。画廊封面沿用原有裁切和比例。

点击封面后，在当前浏览器标签进入充满窗口的作品详情 `project.html?id=<作品 ID>`，支持直接访问、刷新和分享。正文展示完整双页 PDF 图片，不显示额外分类、页码或逐页说明。跨页逐张纵向排列，页间及两侧留白，圆角框配柔和阴影。顶部返回按钮旁的胶囊显示完整作品名，点击可回到作品顶部；右侧「上一个」「下一个」为箭头加文字的胶囊按钮。手机端自动分行，长作品名完整换行。

所有悬浮按钮和滑条胶囊采用 28 像素模糊的毛玻璃材质，外框统一为透明度约 44% 的白色 1 像素细线，去掉内侧高光叠加，保留柔和阴影。操作栏不预建透明度合成层，使返回键、标题栏和前后切换按钮能够实际模糊背后的 PDF 与点阵。顶部按钮向下滚动隐藏，向上滚动、鼠标移向顶部或键盘 Tab 操作时恢复。点击某张 PDF 可全视口查看：桌面按住鼠标左键拖动，滚轮围绕指针位置连续缩放；手机双指捏合缩放，也可单指拖动。底部保留 5%–200% 连续滑条，去掉可见百分比，辅助阅读标签仍提供比例。原尺寸与适应窗口快捷按钮位于缩放滑条左侧，两者组成底部居中控制区。返回入口使用 `#work/<作品 ID>` 回到对应作品，浏览器前进和后退保留页面及阅读位置。

PDF 末尾显示下一个作品的完整名称、动态图形箭头和环形滚动进度。到达底部后，再开始一次向下滚动或向上划动即可进入下一个作品；追加滚动阈值再次从 240 提高至 360，向上滚动可取消未完成的切换。到达底部时的惯性滚动不会直接触发切换，放大查看中也不会触发。提示本身可点击，键盘同样支持继续浏览；最后一个作品之后回到第一个作品。

点击作品阅读页面的留白可返回画廊，点击单张放大界面的留白可回到阅读页面。简历打开后直接进入可缩放界面，点击留白、返回按钮或按 Esc 直接回到个人信息页。实际点在图片或控件内时保留其操作；拖动、滚动、捏合和多指触摸不会触发留白返回。手机边缘留白按原始触点坐标识别，避免浏览器把留白点击吸附到邻近图片上。

作品打开时，当前内容先淡出，随后 PDF 阅读界面淡入；退出时反向切换。画廊、阅读和前后作品切换共用同一文档、同一个背景 WebGL 画布及持续推进的动画时间，不刷新或重建背景，也不使用独立背景遮罩。地址通过 History API 更新，`index.html` 与 `project.html` 使用同一应用外壳，直接访问详情链接仍有效。系统设置减少动态效果时直接完成导航。

阅读页和大图留白直接显示持续运行的首页点阵背景，由 `docs/app.js` 统一调用 `docs/atmosphere.js`，保留流动光影、点阵漂移与呼吸、鼠标附近点阵放大。系统设置减少动态效果时暂停背景流动，仍可使用鼠标交互。

## 页面行为

- 直接打开作品或简历链接时，先加载阅读界面。需要进入首页时再加载三维画廊与人像，两种视图共用同一个动画背景画布。
- 点阵保留原有分辨率和动效参数。渲染跳过未被点阵覆盖的计算，重复使用画廊曲面和文字遮罩，滚动位置稳定时省去重复的进度计算和文字更新。
- 欢迎页的「James · Portfolio」在桌面使用 15 像素字号，手机使用 14 像素字号。主荔枝枝干底部沿圆弧展宽，点阵的颜色和起伏逐渐融入果皮。
- 开场文字消失后，先进入个人介绍，再进入五个作品的三维曲面画廊。左上角的细圆环和中心圆点与「李智个人作品集」垂直居中对齐，随个人介绍一起渐入。鼠标悬停或键盘聚焦时，标志与文字同步覆盖为强调色。
- 个人介绍包括黑白透明人像、偏移红色轮廓、花体 James 签名三个独立图层，随鼠标轻微错位；签名下方的人像渐变模糊。
- 桌面端荔枝从开场一次平滑放大到目标尺寸，个人介绍与作品画廊共用同一基础大小和位置；所有阶段均保留轻微鼠标位移。个人信息与标签以不同幅度跟随鼠标，暂停或减少动态效果时回到基础位置。
- 桌面端照片略微右移，照片、浅红蒙版和 James 签名同步放大约 10%，保留三个图层的独立视差。右侧个人信息下方为横向矩形技能标签区域。标签活动范围向左扩展 72–160 像素、向下扩展 30 像素，保留原有淡入淡出与排斥避让规则，交互区域随视觉位置同步移动。
- 手机端人像和荔枝各向中间靠近 8–16 像素；标签区域下移 16 像素、左右各扩展 12 像素。人像仍保留此前的缩放、上移与分层动效。
- 手机画廊加大作品封面的纵向间距，补偿透视造成的间距压缩，并平滑淡出远端卡片，避免封面互相遮挡。首个作品之后，各作品之间保持相同滚动间距。
- 人像轮廓使用更柔和的浅红色 `#E68C95`，图层不透明度为 `.78`。到岗信息与求职意向使用相同字号和颜色。
- 姓名使用 Medium 字重，求职意向和到岗日期使用 Regular，联系方式和技能标签使用 Light。电话、邮箱链接可直接调用相应应用。
- 「查看简历」打开后立即进入全屏可缩放界面，使用用户提供的简历原图，无需再次点击。支持拖动、滚轮、双指捏合、连续滑条和原尺寸操作；点击标题可重新适应窗口，点击留白、返回按钮或按 Esc 一次返回原来的个人信息位置。地址为 `project.html?id=resume`，支持刷新和历史恢复；没有中间阅读列表、前后作品切换或底部作品提示。内容进出仍淡入淡出，动态背景保持连续。
- 简历阅读页标题右侧的「下载简历」下载附件原件 `李智-个人简历.pdf`。
- 十个毛玻璃技能标签循环淡入淡出，最多同时存在五个，每个存续 4.45 秒；鼠标排斥与标签间避让共同防止重叠。
- 鼠标悬浮作品封面出现毛玻璃「查看项目」胶囊。
- 悬浮某个作品封面时，胶囊文字和图标、卡片圆角边框、当前作品编号、滚动提示的动态图标采用该作品主题色。背景以同色相、低饱和高明度的浅色保留流动光影；移开后平滑恢复默认状态。
- 画廊和阅读界面使用上述作品全名。左上角菜单中的包装研究显示为「探究外卖包装对用户行为意向的影响」，链接到同一个作品。
- 点击作品或使用键盘作品列表进入独立全页详情，支持前后作品切换、完整跨页滚动、大图查看。Esc 先退出大图，再返回画廊；左右方向键切换作品。
- 作品总数、滚动长度和索引根据作品目录计算。
- 桌面端缩短个人介绍到画廊、画廊到首个封面的过渡；手机端延长开场荔枝放大完成后的停留，缩短个人信息展示到荔枝开始移动的等待，延长荔枝离开信息区到画廊的移动段，再缩短画廊到首个封面的过渡。场景、页面高度、作品锚点和进度条共用同一换算。
- 界面字体使用用户提供的 HarmonyOS Sans SC 字体子集，保留原有字重与点阵动效；人像下方的花体 James 使用单独的 Lobster 字体子集。
- 点击个人介绍或画廊左上角的圆环标志或「李智个人作品集」可开关导航。鼠标悬停时展开，移出品牌和菜单后收起，也可按 Esc 或点击空白处关闭。个人信息和个人作品定位到对应区段，简历及各作品直接打开。毛玻璃面板从左侧滑入，条目由上到下淡入。系统减少动态效果时即时展开。
- WebGL 不可用时显示静态作品列表。

作品图片来自用户提供的个人作品集，未改写设计内容。人像由用户提供的 `IMG_0140.jpg` 最右侧人物提取并转换为黑白透明图。简历查看使用用户提供的 `个人简历.jpg`，下载使用 `李智-个人简历.pdf` 原件。

Three.js 和 Lenis 的许可证位于 `docs/vendor/`。HarmonyOS Sans SC 来自用户提供的字体文件，按当前界面用字精简并保留字体元数据。添加新文案时应重新生成包含新增字符的四种字重子集。James 签名字体来自 [Google Fonts 的 Lobster](https://github.com/google/fonts/tree/main/ofl/lobster)，遵循 SIL Open Font License 1.1；许可证随字体保存在 `docs/assets/profile/Lobster-OFL.txt`。

`docs/timeline.js` 使用设备独立的单调平滑曲线，将原场景进度与实际滚动距离分开。桌面个人介绍约在 0.56–0.84 个视口高度时进入，约在 1.43 开始淡出。从个人信息锚点滑到开始淡出的距离缩短了 0.11 个视口高度。画廊完整出现约在 1.71，首个作品居中约在 2.29。手机荔枝从欢迎页初始位置与尺寸直接平滑移动到个人信息位置，约在 1.29 个视口高度时到位，省去中央放大再缩小的过程。个人介绍在 1.02–1.29 时进入，荔枝约在 1.55 开始离开信息区，画廊完整出现约在 2.70，首个作品居中约在 3.32。之后各作品之间约 0.37 个视口高度，总距离桌面约 3.93、手机约 4.96。页面高度、动画进度和作品锚点使用 `sceneToPhysical` 与 `physicalToScene` 同步换算。

荔枝沿用同一个三维点阵对象。桌面端基础姿态统一由 `docs/timeline.js` 的 `desktopFruitPose` 提供：水平居中，中心高度为视口的 54.5%，直径取 335 像素、视口高度的 39%、视口宽度的 24% 三者最小值；开场到达目标后，个人介绍与作品画廊保持该基础姿态，并共享鼠标位移动效。手机端由 `mobileFruitPose` 提供欢迎页直接到介绍位置的过渡；离开介绍后仍平滑回到画廊位置和尺寸。
